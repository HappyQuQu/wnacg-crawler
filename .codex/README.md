# Codex 项目规范入口

本目录保存给 Codex/AI coding agent 使用的项目级上下文和开发约束。`skills/` 目录是可复用技能，不要把项目规范混进 skill 内部。

推荐读取顺序：

1. `PROJECT_CONTEXT.md`：项目目标、当前架构和关键决策。
2. `ENGINEERING_RULES.md`：开发边界、代码风格、模块职责。
3. `VALIDATION.md`：每类修改完成后的验证清单。
4. `NEXT_STEPS.md`：当前优先级和接手路线。

权威产品与技术文档仍在 `docs/`：

- `docs/PRD.md`
- `docs/ARCHITECTURE.md`
- `docs/API.md`
- `docs/DATA_MODEL.md`
- `docs/FLOWS.md`
- `docs/UI_SPEC.md`
- `docs/PROGRESS.md`
