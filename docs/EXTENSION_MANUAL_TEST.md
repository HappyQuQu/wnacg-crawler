# Chrome 扩展手动验收指南

## 1. 前置条件

后台服务已启动：

```bash
uvicorn backend.app.main:app --reload --host 127.0.0.1 --port 8080
```

前端管理台已启动：

```bash
npm run dev -w frontend
```

扩展已构建：

```bash
npm run build:extension
```

可选：生成 zip 分发包。

```bash
npm run package:extension
```

## 2. 生成扩展 Token

打开后台管理台：

```text
http://127.0.0.1:5173/
```

进入设置页，点击生成扩展 Token。生成后复制 Token。

## 3. 加载未打包扩展

1. 打开 Chrome。
2. 进入 `chrome://extensions/`。
3. 打开右上角开发者模式。
4. 点击加载已解压的扩展程序。
5. 选择项目目录下的 `extension/`。

加载成功后应看到扩展名称：

```text
WNACG Downloader
```

## 4. 配置扩展

打开扩展详情或右键扩展图标进入选项页，填写：

```text
Backend URL: http://127.0.0.1:8080
Admin URL:   http://127.0.0.1:5173
Token:       后台设置页生成的 Token
```

保存后打开 popup，应能看到后台连接正常。

本地地址权限覆盖 `127.0.0.1` 和 `localhost` 的各端口；Docker 映射到其他端口时，后台地址应填写实际端口。地址返回 404 时弹窗提示检查地址和端口，返回 401/403 时提示更新 Token。

## 5. 验收用例

- 后台未启动时，popup 显示连接失败提示。
- 后台启动且 token 正确时，popup 显示连接正常。
- 在支持的 WNACG 页面打开 popup，可以识别当前 manga_id。
- 点击加入队列后，后台任务列表出现对应任务。
- 对已存在或下载中的 ID，popup 能显示当前本地状态。
- token 错误时，扩展接口返回鉴权失败，不创建任务。

### 详情页入口

1. 重新加载扩展后，刷新原站 `photos-index-aid-<ID>.html` 详情页。
2. 标题下方应显示 WNACG Downloader 操作条，包含作品 ID、本地任务状态、加入队列、打开后台和刷新状态。无法定位标题时，操作条显示在右下角。
3. 翻页详情地址 `photos-index-page-<页码>-aid-<ID>.html` 以及带查询参数的地址也应显示同一作品的入口；图片阅读页不显示此操作条。
4. 只打开页面或刷新状态不会创建任务；下载中的作品显示“已在队列”，已完成的作品显示“已下载”，暂停的作品应在后台继续。
5. 后台离线或 Token 无效时显示连接提示并禁用加入按钮。恢复后台或修改扩展配置后，点击刷新状态，或等待页面可见时的 15 秒自动刷新。
6. 打开后台应使用扩展配置的管理台地址。列表页原有逐项加入入口应保持正常。

点击加入队列会提交真实任务；仅在明确需要验证真实下载时执行，并使用用户指定的 ID。

## 6. 当前限制

- 扩展只负责识别页面和投喂任务，不参与下载、校验、打包。
- 已在独立 Chrome for Testing 实例加载扩展，并验证工具栏原生弹窗尺寸为 380 × 580、连接和错误提示、设置入口；日常 Chrome 中仍需重新加载扩展并刷新原站页面。
- 如要验证完整下载链路，应使用用户明确给出的真实漫画 ID。

## 7. 界面与连接设置验收

- 弹窗、独立选项页及原站入口采用与后台一致的系统字体、浅灰背景、白色卡片、蓝色操作和线性 SVG 图标；深色模式跟随操作系统，减少动画偏好生效。
- 原生工具栏弹窗固定为 380 × 580，页面不应横向滚动；任务列表内部滚动，页脚和连接设置的保存操作保持可见。统计使用完整任务列表，“进行中”包含待确认、排队、运行和暂停，并分别显示运行/等待/暂停数量。
- 任务进度可切换进行中和需处理（失败/部分完成）；未知总数不显示 0%，目录与图片解析使用对应的计数单位。任务行只打开后台，不执行暂停、重试或文件操作。
- 当前作品只识别支持域名的作品详情地址，包含带查询参数和分页的详情页；其他站点、列表页和阅读页不会由 popup 自动识别并提交。列表页仍可使用内容脚本的逐项入口。
- 已下载、暂停和已在队列的作品禁用重复加入；本地状态查询失败时同样禁用，刷新后可恢复。仅展示、查询、测试连接不会创建任务。
- 弹窗与独立选项页使用同一连接表单，支持 HTTP/HTTPS 地址校验、Token 遮蔽/显示/粘贴/清空、未保存提示、撤销和测试连接。测试未保存的地址和 Token 不写入扩展存储。
- 保存失败保留编辑；保存成功但服务离线时，分别提示“已保存”和连接原因。清除 Token 在保存后才生效，关闭弹窗中的设置视图后再次遮蔽 Token。
- 重新执行 `npm run package:extension` 后，ZIP 应包含 `ui.css`、图标和 `dist/connection.js`。已加载项目 `extension/` 目录时，在 Chrome 扩展管理页点击此扩展的“重新加载”，再刷新原站页面。
