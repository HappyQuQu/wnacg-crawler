# 核心流程文档

版本：v0.1  
日期：2026-05-26

## 1. 流程总览

系统入口分为四类：

```text
后台手动输入
后台批量导入
浏览器扩展投喂
CLI/File Watch 自动导入
```

所有入口最终都进入统一流程：

```text
输入解析 -> 任务预检 -> 加入队列 -> 下载执行 -> 完整性校验 -> ZIP 打包 -> 资料库归档
```

## 2. 手动输入下载

### 2.1 用户流程

1. 用户打开后台管理。
2. 在“添加任务”输入框粘贴 ID 或 URL。
3. 点击“解析”。
4. 系统展示预检列表。
5. 用户选择任务。
6. 点击“加入队列”。
7. 系统开始下载或排队。

### 2.2 输入示例

```text
123456
https://www.wnacg.com/photos-index-page-1-aid-298731.html
298732, 298733
```

### 2.3 系统处理

1. 按换行、空格、逗号、中文逗号拆分。
2. 从 URL 中提取 `aid-<id>`。
3. 校验 ID 仅包含数字。
4. 去重。
5. 查询本地数据库。
6. 对未知项拉取元信息。
7. 返回预检结果。

### 2.4 预检状态

```text
ready       未下载，可加入队列
exists      已存在，可查看
partial     部分完成，可补全
running     下载中，不重复加入
invalid     输入无效
failed      预检失败，可重试
```

### 2.5 验收标准

- 混合 ID/URL 输入能正确解析。
- 重复 ID 只出现一次。
- 无效输入不会创建任务。
- 已下载项不会被误判为未下载。

## 3. 批量导入

### 3.1 用户流程

1. 用户拖入 `.txt` 文件或选择文件。
2. 系统读取内容并解析。
3. 展示有效项、重复项、无效项。
4. 用户选择处理策略。
5. 系统加入待确认或下载队列。

### 3.2 处理策略

```text
仅添加未下载
补全缺失
全部加入待确认
忽略已完成
导出无效项
```

### 3.3 验收标准

- 1000 行文本可以解析。
- 重复项会汇总展示。
- 无效项可导出。
- 导入不会阻塞整个页面。

## 4. 浏览器扩展添加

### 4.1 详情页流程

1. 用户访问原站详情页。
2. 扩展识别当前页面 ID。
3. 用户打开 popup。
4. popup 查询后台状态。
5. 用户点击“加入队列”。
6. 扩展调用后台 API。
7. 后台返回结果。

### 4.2 列表页流程

1. 用户访问搜索页、分类页或作者页。
2. 扩展解析当前页所有 ID。
3. 用户点击“加入本页全部”。
4. 扩展批量提交到后台。
5. 后台将任务进入待确认。

### 4.3 扩展失败场景

```text
后台未启动
Token 无效
页面类型未识别
列表页未解析到 ID
后台 API 返回错误
```

### 4.4 验收标准

- 后台未启动时 popup 显示明确提示。
- 扩展不会直接下载图片。
- 扩展提交重复 ID 时后台返回已存在状态。

## 5. 下载执行

### 5.1 阶段流程

```text
queued
  -> fetching_info
  -> fetching_pages
  -> resolving_images
  -> downloading
  -> verifying
  -> zipping
  -> completed
```

异常分支：

```text
failed
partial
paused
cancelled
```

### 5.2 阶段说明

`fetching_info`：获取标题、封面、目录页数量。  
`fetching_pages`：获取所有目录页 HTML。  
`resolving_images`：解析所有图片详情页并提取真实图片 URL。  
`downloading`：按 `max_thread` 并发下载图片文件。  
`verifying`：检查文件大小、格式和数量。  
`zipping`：生成 ZIP。  
`completed`：任务完整结束。

### 5.3 下载要求

- 已有有效文件跳过。
- 已有无效文件重新下载。
- 单个漫画内图片下载按设置页并发数 `max_thread` 执行。
- 批量任务会并发启动多个漫画下载任务。
- 单张图片失败不应导致其他图片停止。
- 全部协程结束后必须计算完整度。
- 不完整任务进入 `partial`。

## 6. 失败恢复

### 6.1 可恢复对象

```text
任务
目录页
图片详情页
图片文件
ZIP 文件
```

### 6.2 用户操作

```text
重试任务
只重试失败图片
重新解析图片地址
重新获取目录页
重新校验文件
重新打包 ZIP
```

### 6.3 验收标准

- 失败原因能在 UI 看到。
- 重试不会创建重复文件。
- 重试成功后状态自动刷新。
- 失败任务不会显示为完成。

## 7. 资料库管理

### 7.1 用户流程

1. 用户进入资料库。
2. 搜索 ID 或标题。
3. 查看完整度和 ZIP 状态。
4. 对部分完成项执行补全。
5. 对完整项打开目录或重新打包。

### 7.2 资料库状态

```text
completed   已完成
partial     部分完成
failed      下载失败
archived    已归档
missing     文件缺失
```

### 7.3 验收标准

- 资料库状态来自数据库和文件校验结果。
- 文件被用户手动删除后，重新校验能识别缺失。
- 同名作品不会互相覆盖。
