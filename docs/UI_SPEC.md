# UI 开发规格

版本：v0.1  
日期：2026-05-26  
参考原型：`docs/prototype/index.html`

## 1. 设计方向

后台 UI 采用 Apple 风格的浅色管理界面：

- 浅灰页面背景
- 白色/半透明面板
- 轻量毛玻璃工具栏
- 蓝色主操作
- 绿色成功、橙色部分完成、红色失败
- 克制阴影
- 高信息密度但不拥挤

不使用 emoji 作为图标。图标统一使用 SVG 图标或后续接入 Lucide。

## 2. 页面结构

一级页面：

```text
控制台
下载队列
本地资料库
设置
```

MVP 可以先使用单页应用切换，也可以分路由实现。

## 3. 控制台

### 3.1 目标

控制台是默认首页，聚合：

- 关键指标
- 添加任务
- 预检列表
- 当前任务详情

### 3.2 指标卡片

展示：

```text
待确认
下载中
完整度
失败项
```

每张卡包含：

- 指标名称
- 数值
- 辅助描述
- 图标

### 3.3 添加任务面板

组件：

- 多行输入框
- 解析按钮
- 加入待确认按钮
- 读取剪贴板按钮
- 导入文件区域
- 预检结果表格

输入框支持：

```text
ID
详情页 URL
多个 ID/URL 混合
换行、逗号、空格分隔
```

### 3.4 预检表格

字段：

```text
ID
标题
页数
本地状态
来源
操作
```

本地状态：

```text
未下载
已完成
缺 N 张
下载中
失败
```

操作：

```text
加入队列
补全
查看
重试
```


## 9. 组件规格

### 9.1 状态标签

颜色：

```text
未下载/下载中：蓝色
已完成：绿色
部分完成：橙色
失败：红色
```

标签需要同时使用颜色和文字，不允许只靠颜色表达状态。

### 9.2 按钮

按钮类型：

```text
primary     主操作
secondary   次操作
icon        图标操作
danger      高风险操作
```

所有按钮需要：

- hover 状态
- focus-visible 状态
- disabled/loading 状态
- 不因 hover 造成布局位移

### 9.3 表格

表格要求：

- 桌面端可横向容纳主要列。
- 移动端允许横向滚动或改为卡片。
- 表头固定可后续实现。
- 行 hover 只改变背景，不改变高度。

### 9.4 Toast

用于短反馈：

```text
解析完成
加入队列
配置保存成功
重试已开始
```

错误不只用 Toast，重要错误要留在任务详情或失败列表中。

## 10. 响应式要求

断点：

```text
mobile: 375px+
tablet: 768px+
desktop: 1024px+
wide: 1440px+
```

要求：

- 移动端无页面级横向滚动。
- 侧边栏在窄屏变成图标导航。
- 指标卡片移动端单列。
- 添加任务区移动端上下排列。
- 表格移动端可横向滚动。

## 11. 可访问性

要求：

- 所有输入有 label。
- 所有图标按钮有 title 或 sr-only 文本。
- 键盘 focus 清晰可见。
- 文本对比度满足 WCAG AA。
- 异步操作有 loading 或 toast。
- 支持 prefers-reduced-motion。

## 12. 原型与实现关系

`docs/prototype/index.html` 是视觉和布局参考，不是最终代码结构。

实现时可以：

- 拆成组件
- 接真实 API
- 替换静态数据
- 接入真实图标库

不应照搬：

- 静态假数据
- inline 事件
- 单文件脚本组织方式
