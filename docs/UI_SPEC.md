# UI 开发规格

版本：v0.1  
日期：2026-05-26  
参考原型：`docs/prototype/index.html`

## 1. 设计方向

后台 UI 采用 Apple 风格，支持浅色、深色和跟随系统三种外观：

- 浅色模式使用浅灰背景、白色/半透明面板
- 深色模式使用深灰背景、分层深色面板与高对比度文字
- 轻量毛玻璃工具栏
- 蓝色主操作
- 绿色成功、橙色部分完成、红色失败
- 克制阴影
- 高信息密度但不拥挤

默认跟随系统，系统外观变化时自动更新。设置页的外观选项立即预览，点击“保存所有设置”后通过配置 API 持久化；刷新页面时恢复后台保存的偏好。深色模式覆盖页面、表单、表格、弹窗、通知及状态标签。

不使用 emoji 作为图标。图标统一使用 SVG 图标或后续接入 Lucide。

## 2. 页面结构

一级页面：

```text
控制台
下载队列
本地资料库
设置
```

MVP 可以先使用单页应用切换，也可以分路由实现。

## 3. 控制台

### 3.1 目标

控制台是默认首页，聚合：

- 运行中、待开始、需关注和本地作品统计
- 任务进度与阶段分布
- 失败、部分完成任务的处理入口
- 资料库最近完成的作品和少量最近动态
- 添加任务、刷新和管理入口

### 3.2 指标卡片

展示：

```text
运行中：全量任务中 status=running 的数量
等待开始：queued 与 pending 数量，并分别展示明细
需要关注：failed 与 partial 数量
本地作品：资料库项目数量，补充完整作品和已打包数量
```

每张卡包含：

- 指标名称
- 数值
- 辅助描述
- 图标

任务列表的 5 条预览上限不得影响统计。暂停任务单独展示，不计入运行中；资料库统计独立于任务记录，清除已完成任务后仍应保留。

### 3.2.1 概览布局与交互

- 桌面采用左侧任务进度、右侧待处理问题和最近完成作品的布局，下方保留最近 3 条动态。
- 任务进度可切换运行中、待开始和已暂停，预览最多 5 项，并提供完整任务列表入口。
- 阶段分布按实际运行任务的 stage 统计，不推算下载速度或剩余时间。
- 点击任务打开相应任务详情；问题卡片跳转同时包含 failed/partial 的“需处理”筛选；“全部日志”直接打开日志页。
- 最近完成作品来自资料库，点击打开对应作品详情；搜索支持作品标题和 ID。
- 窄屏改为双列指标、单列内容；保留四个主导航入口，避免文字竖排、标题溢出和横向页面滚动。
- 初次加载展示骨架屏，真实空列表展示引导；刷新和重试具备 loading/disabled 状态。支持深色模式和键盘切换进度标签。

### 3.3 添加任务面板

组件：

- 多行输入框
- 解析按钮
- 加入待确认按钮
- 读取剪贴板按钮
- 导入文件区域
- 预检结果表格

输入框支持：

```text
ID
详情页 URL
多个 ID/URL 混合
换行、逗号、空格分隔
```

### 3.4 预检表格

字段：

```text
ID
标题
页数
本地状态
来源
操作
```

本地状态：

```text
未下载
已完成
缺 N 张
下载中
失败
```

操作：

```text
加入队列
补全
查看
重试
```

## 4. 下载任务页

### 4.1 布局与统计

与概览页共用字体、间距、圆角面板、连接状态、蓝色主操作和四列统计卡片。统计来自完整任务列表，不受搜索和当前分类影响：

- 全部任务：所有下载记录，含已取消任务。
- 进行中：运行、排队、待确认与暂停任务，并分别展示运行、等待和暂停数量。
- 已完成：可清除的完成记录，清除后保留资料库和本地文件。
- 需要关注：失败与部分完成的任务，并展示各自数量。

桌面左侧为下载列表、右侧为吸顶详情。窄屏只显示列表，点击任务通过原生模态弹窗查看详情；支持 Escape、关闭按钮和返回列表。取消任务、清除记录时先关闭详情弹窗，再展示确认对话框，避免对话框被遮挡。

### 4.2 列表与操作

- 可切换列表与卡片视图，沿用本地显示偏好。
- 列表封面为 96 × 128px，手机为 80 × 112px；标题最多两行。进度放在标题下方，为作品识别留出空间。卡片以 280px 高的大封面为主，手机增至 320px；封面完整显示，不裁切。其余展示作品 ID、更新时间、状态、阶段及进度，详情可展开完整标题。
- 行内只展示当前状态可用的暂停、开始、继续或重试操作；完成任务用完成标识，清除记录在详情中操作。
- 所有控制操作具备 disabled/loading 状态，不让失效按钮占用列表空间。
- 有总数时显示当前阶段的百分比与计数：目录阶段按目录页计数，解析图片阶段按图片页计数，下载阶段按图片计数；不估算速度、剩余时间或整项任务的总进度。
- 尚无总数时显示阶段与说明，不显示误导性的 0%。运行任务不能显示为“等待开始”。
- 错误原因保留在列表摘要和详情中；实时更新行内进度与当前详情。
- 空分类、无搜索结果和初次加载分别显示对应引导或骨架屏。

### 4.3 筛选与日志

分类为全部、进行中、已完成、需处理和日志。“需处理”同时包含 failed/partial。支持键盘切换标签，以及搜索标题、ID、状态、来源和任务 ID。详情始终来自当前筛选结果，避免显示其他分类的任务。

运行日志采用可换行的记录列表，展示时间、级别、作品 ID、阶段、消息和事件名，额外数据可展开查看。支持搜索和刷新。

## 5. 任务详情

详情顶部展示 320px 高的完整封面，标题与状态放在封面下方。点击“放大查看”打开适应视口的大图，支持关闭按钮、Escape 和返回原详情；模糊封面模式保持模糊且不提供放大入口。详情按顺序展示作品信息、阶段进度、失败原因、阶段/来源/重试次数/任务 ID/时间信息和可折叠实时日志。失败任务默认展开日志，其他任务可按需展开。底部固定显示当前可用的暂停、开始、继续、取消、重试或重新下载操作，以及原始页面链接；已完成记录提供单项清除入口。

清除已完成任务保留资料库与本地文件，单项和全部清除均需确认。资料库中的文件校验、重新打包和问题图片修复使用资料库详情入口。

## 6. 本地资料库页

### 6.1 布局与统计

沿用概览和下载任务页的标题、连接状态、添加下载入口、统计卡片、间距和面板样式，支持浅色、深色和窄屏。

- 四项统计为本地作品、完整作品、需要关注和已打包；数值来自完整资料库，不受搜索和筛选影响。
- “需要关注”包含未完整、失败和文件缺失的作品，排除仍有待确认、排队、运行或暂停任务的作品。
- 有效文件数量与 ZIP 大小根据后端返回值汇总，不估算图片总占用空间。
- 分类改为横向标签：全部、完整、需处理、进行中。更多状态保留部分完成、失败和文件异常；打包状态独立筛选，可与作品状态组合。
- 工具栏保留排序、升降序和列表/卡片切换。窄屏状态标签独占一行，避免隐藏主要分类。
- 默认展示完整宽度的作品列表；选中作品后桌面显示右侧详情，关闭后恢复完整宽度。窄屏通过原生模态弹窗查看，支持 Escape 与关闭。

### 6.2 作品与批量操作

列表使用 96 × 128px 封面，手机保留 80 × 112px，不随详情栏打开而缩小。卡片顶部展示 280px 高的大封面，手机为 320px，标题和文件状态在下方。卡片和列表展示标题、ID、状态、有效文件数量、文件完整度、打包状态和错误摘要；封面完整显示，不裁切。封面失败时显示占位图标，长标题在详情中可展开。空资料库、无匹配结果与加载中使用不同提示。

- 勾选与查看详情为独立控件，支持键盘操作；全选支持部分选中的状态。
- 选择作品后显示批量操作栏，包含下载所选、删除所选和取消选择。切换视图保留选择，切换搜索或分类清空选择。
- 多选下载仍为每项作品一个独立文件，选 10 项生成 10 次浏览器下载；不合并成单个归档。
- 下载清单保留独立链接、无法下载的原因与重新发起入口，便于处理浏览器连续下载拦截。
- 删除前确认，默认保留本地文件；勾选后才删除图片、原图和 ZIP。有活跃任务的作品由后端跳过，批量删除失败项保留选择。
- 作品仍有活跃任务或有效图片尚未完整时，单项下载不可用；批量请求逐项反馈无法下载的原因。

### 6.3 作品详情

顶部展示 320px 高的完整封面，可点击放大查看；大图支持 Escape 与关闭按钮，关闭后保留原详情弹窗与焦点。模糊封面偏好保持生效。其后按作品信息、文件完整度、问题原因、缺失/失败文件数、ZIP 状态、文件维护、本地位置和文件明细组织。校验、问题文件重试和重新打包集中在详情，底部固定下载、删除与原始页面入口。有未结束的任务时暂停文件维护操作。

文件明细支持只看问题、刷新和查看路径。详情请求期间显示骨架屏，失败时提供重新加载；切换作品不显示旧明细，迟到的请求不覆盖新选择，关闭或删除后的请求不能重新打开详情。列表排序同样忽略迟到响应。

概览最近完成入口在桌面与手机上都直接打开对应作品详情。手机端从详情执行删除或下载时先关闭详情，再显示确认或文件清单，避免遮挡。

## 7. 设置页

### 7.1 布局与分组

沿用概览、下载任务和资料库的标题、连接状态、卡片、字体与间距。顶部以后台已保存的值展示图片并发、ZIP 归档、网络代理和扩展访问配置；表单编辑不应提前改变这些生效摘要。

五组设置：

- 外观与显示：浅色、深色、跟随系统；主题立即预览，保存后持久化。模糊封面立即生效，仅保存在当前浏览器，不计入后台待保存项。
- 下载与存储：后台下载目录、图片并发、请求间隔、超时和自动打包 ZIP。
- 图片压缩：启用压缩、大小上限、保留原图和允许缩小分辨率；显示对新图片、动画和已有有效文件的处理说明。
- 网络代理：启用开关、地址、端口及可选认证。关闭时保留已填写内容，并禁用对应控件。
- 浏览器扩展：当前后台地址、遮蔽显示的 Token、复制、生成与清除操作。

桌面右侧提供设置目录、保存状态、待保存项和配置文件位置；窄屏改为横向目录与底部保存/撤销栏。搜索支持设置名称与关键字，无匹配时可恢复全部设置；从目录或摘要跳转时清空筛选并定位对应组。设置搜索与作品搜索在跨页时分别清空，避免沿用不相关条件。

### 7.2 校验与保存

- 下载目录必填；路径按后台环境解释，容器部署填写容器内目录。
- 图片并发为 1–20 整数，请求间隔 0–10000 毫秒，超时 5–120 秒。
- 图片大小上限为 1–102400 KB 整数；代理端口为 1–65535 整数，启用代理时地址必填；Token 不超过 256 字符。
- 错误显示在对应字段；有错误或没有更改时禁用保存。手机底部可直接定位错误组。
- 保存期间禁用表单，失败时保留编辑并提供重试反馈；成功后以服务端返回的实际生效配置更新摘要与表单。
- 保存使用现有热重载接口，无需重启后台。环境变量覆盖导致未应用的字段必须显示提示，不能以输入值冒充实际生效值。

### 7.3 编辑与扩展操作

后台读取快照与用户草稿分别保存。定时刷新、手动刷新及其他页面的任务操作，不得覆盖正在编辑的字段；未编辑的字段可以更新为后台新值。撤销仅恢复最近读取的后台配置，不写入后台，也不影响本机的模糊封面偏好。迟到的读取结果不能覆盖新的保存结果。

Token 默认遮蔽，可显示或复制；后台地址与 Token 使用独立的复制反馈，剪贴板失败需提示手动复制。生成新 Token 沿用确认流程并立即持久化，其他未保存设置继续保留。手动修改和清除 Token 在统一保存后才生效。

首次读取显示骨架屏，读取失败可重试；保存失败、环境覆盖、未保存和无更改分别呈现对应状态。支持深色、跟随系统、键盘操作及减少动画偏好。

## 8. 浏览器扩展

扩展与后台沿用同一套系统字体、卡片圆角、背景层次、蓝色主操作和状态颜色；工具栏图标与后台下载标识一致。弹窗、独立选项页共享 `extension/ui.css`，跟随操作系统深浅色并尊重减少动画偏好。

### 8.1 弹窗

固定 380 × 580，保留 Chrome 文档本身的显式宽度，避免内在尺寸收缩。顶部分别展示连接状态、本地作品/进行中/已完成的全量统计和当前作品。任务进度包含进行中与需处理分类，列表内部滚动，页脚入口固定可见。显示阶段真实计数，未知总数不展示 0%。

只识别支持域名的详情页 ID；重复、已完成与暂停作品禁用加入，暂停应在后台继续。状态查询失败时不开放提交。打开弹窗、切换任务分类、刷新和测试连接都不创建任务，用户点击加入后才提交。

### 8.2 连接设置

弹窗设置与独立选项页共用连接逻辑，包含后台服务地址、管理页面地址和 Token。地址要求 HTTP/HTTPS；Token 默认遮蔽，可粘贴、显示与清空。显示未保存项和撤销入口，测试连接可使用草稿但不写入存储。保存后检查连接，区分存储失败与后台未连接。

独立选项页采用左侧表单、右侧测试结果和连接步骤的布局，窄屏改为单列。原站列表按钮、统计条和详情操作条使用相同图标与状态语言，不改变站点其他界面样式。

## 9. 组件规格

### 9.1 状态标签

颜色：

```text
未下载/下载中：蓝色
已完成：绿色
部分完成：橙色
失败：红色
```

标签需要同时使用颜色和文字，不允许只靠颜色表达状态。

### 9.2 按钮

按钮类型：

```text
primary     主操作
secondary   次操作
icon        图标操作
danger      高风险操作
```

所有按钮需要：

- hover 状态
- focus-visible 状态
- disabled/loading 状态
- 不因 hover 造成布局位移

### 9.3 表格

表格要求：

- 桌面端可横向容纳主要列。
- 移动端允许横向滚动或改为卡片。
- 表头固定可后续实现。
- 行 hover 只改变背景，不改变高度。

### 9.4 Toast

用于短反馈：

```text
解析完成
加入队列
配置保存成功
重试已开始
```

错误不只用 Toast，重要错误要留在任务详情或失败列表中。

## 10. 响应式要求

断点：

```text
mobile: 375px+
tablet: 768px+
desktop: 1024px+
wide: 1440px+
```

要求：

- 移动端无页面级横向滚动。
- 侧边栏在窄屏变成图标导航。
- 指标卡片移动端单列。
- 添加任务区移动端上下排列。
- 表格移动端可横向滚动。

## 11. 可访问性

要求：

- 所有输入有 label。
- 所有图标按钮有 title 或 sr-only 文本。
- 键盘 focus 清晰可见。
- 文本对比度满足 WCAG AA。
- 异步操作有 loading 或 toast。
- 支持 prefers-reduced-motion。

## 12. 原型与实现关系

`docs/prototype/index.html` 是视觉和布局参考，不是最终代码结构。

实现时可以：

- 拆成组件
- 接真实 API
- 替换静态数据
- 接入真实图标库

不应照搬：

- 静态假数据
- inline 事件
- 单文件脚本组织方式
