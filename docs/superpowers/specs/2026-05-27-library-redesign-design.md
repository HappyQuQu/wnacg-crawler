# 资料库页面重新设计

## 概述

将资料库页面从"下载状态查看器"升级为"漫画资料库管理系统"。采用三栏布局（左侧分类栏 + 中间内容区 + 右侧详情面板），支持卡片/列表双视图、排序、搜索，为后期对接 Komga/Calibre 和在线阅读预留扩展点。

## 当前状态

- 左右两栏：卡片网格 + 文件明细面板
- 顶部 tab 分段筛选（全部/完整/缺失/失败/文件异常）
- 卡片：68px 缩略图 + 标题/状态/进度/元数据
- 无排序、无视图切换、无批量操作

## 设计

### 布局架构

三栏布局：

| 区域 | 宽度 | 内容 |
|------|------|------|
| 左侧分类栏 | 固定 220px，可折叠 | 分类导航 + 标签筛选 |
| 中间内容区 | 弹性填充 | 搜索/排序/视图切换 + 卡片网格或列表 |
| 右侧详情面板 | 固定 380px，可关闭 | 封面大图 + 元数据 + 操作 + 文件列表 |

响应式规则：
- `> 1200px`：三栏完整显示
- `860px ~ 1200px`：左侧栏折叠为图标模式（48px，仅显示分类图标）
- `< 860px`：左侧栏默认收起，点击展开为 overlay；详情面板全宽显示

交互流程：
1. 默认选中"全部"分类，中间区显示所有资料卡片
2. 点击左侧分类 → 中间区筛选切换
3. 点击卡片 → 右侧滑出详情面板（300ms 动画）
4. 再次点击同一卡片或点击关闭 → 收起详情面板
5. 选中卡片高亮，键盘上下可切换选中项

### 左侧分类栏

```
┌─────────────────────┐
│  资料库              │  标题
│                      │
│ ── 快速筛选 ──       │
│ ● 全部        (128) │
│ ● 完整         (95) │
│ ● 缺失         (12) │
│ ● 失败          (8) │
│ ● 文件异常      (13) │
│                      │
│ ── 打包状态 ──       │
│ ● 已打包        (80) │
│ ● 未打包        (48) │
│                      │
│ ── 标签 ──           │  预留
│ (暂无标签)           │
│                      │
│ [折叠按钮]           │
└─────────────────────┘
```

设计要点：
- 分类用圆点 + 计数 badge，当前选中项高亮
- "快速筛选"和"打包状态"是互斥的单选
- 标签区域本期只预留位置，后期支持多选标签叠加筛选
- 底部折叠按钮可将侧栏收起为 48px 图标栏

分类筛选项与 LibraryFilter 的映射：
- `all` → 全部
- `completed` → 完整
- `partial` → 缺失
- `failed` → 失败
- `missing` → 文件异常（缺失+失败合并）
- `zipped` → 已打包（新增）
- `unzipped` → 未打包（新增）

### 中间内容区

**顶部工具栏**：
- 搜索输入框（搜索 ID、标题）
- 排序下拉菜单：更新时间（默认）| 标题 | 完成度 | 文件数 | 文件大小
- 视图切换按钮：列表 | 卡片
- 刷新按钮

**卡片视图**（默认）：
- 封面占卡片全宽，高度按 3:4 比例
- 标题在封面下方，截断显示 2 行
- ID 用 mono 字体
- 进度条 + 百分比
- 元数据行：图片数、有效数、大小
- 状态用颜色 badge（完整=绿、缺失=黄、失败=红）

**列表视图**：
- 表格列：封面缩略图 | 标题 | 状态 | 完成度 | 图片数 | 大小 | 操作
- 表头可点击排序
- 选中行高亮

### 右侧详情面板

布局：
1. 关闭按钮
2. 封面大图（面板宽度 80%，3:4 比例，居中）
3. 标题（完整显示，可换行）+ ID + 状态
4. 元数据网格：完成度、图片数、大小、缺失数、失败数
5. 操作按钮行：校验、重试问题、打包、原始链接
6. 文件列表区域：
   - 工具栏：只看问题 toggle、全选
   - 可滚动文件列表：序号、文件名、状态、大小、错误信息

### 后端 API 扩展

`GET /api/library` 新增查询参数：

| 参数 | 类型 | 说明 |
|------|------|------|
| `sort_by` | string | 排序字段：`updated_at`（默认）、`title`、`completeness`、`pic_count`、`zip_size` |
| `sort_order` | string | `asc` 或 `desc`（默认 `desc`） |
| `status` | string | 按状态筛选（已有，保持兼容） |
| `zip_status` | string | `zipped` 或 `unzipped` |

排序在 `LibraryService.list()` 中实现，基于 SQLAlchemy query 的 `order_by`。

## 实现范围

本次实现：
- 前端三栏布局 + 分类侧栏 + 卡片/列表视图 + 详情面板 + 排序 + 搜索
- 后端排序/筛选 API 扩展

不包含（后期）：
- 标签系统
- 批量操作
- Komga/Calibre 对接
- 在线阅读器
